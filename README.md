# 독도 해양 지킴이 (Dokdo Marine Monitor)

독도 해역을 파력 발전, eDNA 분석, AI 개체 추적, 시민과학으로 지켜보는 모니터링 시스템을 보여주는 웹 프로토타입입니다.

## 소개

독도 주변 4개 가상 관측 스테이션에서 수중 카메라와 eDNA 채수기가 데이터를 보내온다고 가정하고,
대시보드·실시간 피드·시민 참여·내 생물 도감·시스템 소개 다섯 화면으로 구성한 데모입니다.
화면에 나오는 스테이션 위치, 생물 종, 센서 값, 알림은 모두 서버가 생성하는 가상 데이터이며,
실제 독도 현장의 카메라나 센서와 연결돼 있지 않습니다.

## 주요 기능

- 대시보드: 4개 관측 스테이션 위치를 지도에 표시, 수온 등 센서 값 실시간(가상) 갱신
- 실시간 피드: 가상 수중 카메라 영상 자리에 탐지된 생물 종 알림을 흘려보냄
- 시민 참여: 생물 라벨링에 참여하면 포인트를 얻는 시민과학 체험
- 내 생물: 라벨링으로 모은 생물 도감, 포인트로 교환
- 시스템 소개: 파력 발전·eDNA 분석·AI 개체 재식별(Re-ID)·시민과학을 결합한 구상 설명

## 기술

프런트엔드: React, Vite, Tailwind CSS, react-leaflet(지도), recharts(그래프), framer-motion(애니메이션).
백엔드: Node.js, Express (정적 파일 서빙 + 가상 데이터를 돌려주는 REST API).

## 실행 방법

```bash
npm install
npm run build

cd server
npm install
npm start   # http://localhost:3001 — 빌드 결과물과 API를 함께 서빙
```

개발 중에는 프런트엔드만 따로 띄울 수도 있습니다.

```bash
npm install
npm run dev   # Vite 개발 서버
```
